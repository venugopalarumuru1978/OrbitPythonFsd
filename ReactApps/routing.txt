Routing:- 
----------------
The concept of using for the links b/w components. 

1. Create new react application
2. Create related components
	Login.js
	Register.js
	Contact.js
3. Now install "react-router-dom"  package in terminal
	npm install react-router-dom

4. Create a component "NavBar.js" then write the following code
import { Link } from "react-router-dom";

<p style={{textAlign:"center"}}>
            <Link to="/login">Login</Link>
            &nbsp;&nbsp;&nbsp;|&nbsp;&nbsp;&nbsp;
            <Link to="/reg">Register</Link>
            &nbsp;&nbsp;&nbsp;|&nbsp;&nbsp;&nbsp;
            <Link to="/contact">Contact</Link>
</p>

5.  Now goto "App.js" then write the following code
        <BrowserRouter>
        <NavBar />
        <hr />
        <Routes >
          <Route  path="/login" exact Component={Login} />
          <Route  path="/reg" exact Component={Register} />
          <Route  path="/contact" exact Component={Contact} />
        </Routes>
        </BrowserRouter>
6. run the application
